# heddy

## 모바일 개발 환경 설정
```bash
# iOS 플랫폼 최초 추가
pnpm ios

# Android 플랫폼 최초 추가
pnpm android

```

## 개발 환경 실행

```bash
# 데스크탑
pnpm dev:desktop

# 모바일
pnpm dev:mobile

# iOS
pnpm dev:ios

# Android
pnpm dev:android
```

## 빌드

```bash
# 데스크탑
pnpm build:desktop

# 모바일
pnpm build:mobile

# iOS
pnpm build:ios

# Android
pnpm build:android
```

## 빌드 결과물 미리보기

```bash
pnpm preview:desktop
pnpm preview:mobile
```
